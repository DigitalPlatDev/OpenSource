# OpenSource.ngo Licenses Library

OpenSource.ngo is a nonprofit reference library for open source licenses, with clear provenance and an up-to-date public catalog. Open source licensing, clearly documented.

## What you will find here

- **Public Licenses**: A synced catalog of well-known and lesser-known open source licenses sourced from SPDX.
- **OpenSource.ngo Licenses**: Placeholder pages for upcoming OpenSource.ngo-authored licenses.
- **Policies**: Our provenance, update, and disclaimer policies.

> **Not legal advice.** The content on this site is provided for informational purposes only.
