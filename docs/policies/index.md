# Policies

OpenSource.ngo publishes public license texts with clear provenance and timestamps. We sync from authoritative sources and provide transparency on when and how data was collected.

## Not legal advice

The OpenSource.ngo Licenses site is a reference library only. It does not provide legal advice, and no attorney-client relationship is created by using this site.

## Provenance and update policy

- **Source of public licenses**: SPDX License List data and individual license detail endpoints.
- **Sync cadence**: On-demand via `npm run sync:licenses`.
- **Tracking**: Each license page includes the SPDX ID, source URL, and the last synced timestamp.
